- Versions of the packages are fixed using Renv

# Software Management Plan (SMP)
1. The purpose of this software is to process manufacturing data for use in a Digital Twin. It is meant for researchers taht want to optimise Digital Twins.
2. Version control will be done using git and code is published on Github
3. This software will be made available through [Github](https://github.com/Xelaph/research_software_management).
4. The software is distributed under a CC-BY license.
5. The software will be developed to fit the needs of multiple projects centered around Digital Twins in the group of Manufacturing Systems.
6. The software will be part of the Manufacturing Systems group, which will maintain it.
7. The software will be hosted on Github, which ensures it long-term availability.
8. The software will be integrated in future projects and possibly courses in the Manufacturing Systems group to promote longevity.
9. Software documentation can be found in and next to the [code](code/README.md).
10. Install requirements are managed through Renv
11. This software can be cited by use of the [citation file](CITATION.cff)
12. Tests are available in the [tests](tests/) folder
13. The software will be distributed only through this Github.
